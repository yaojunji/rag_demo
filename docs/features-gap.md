# 企业级 RAG 知识库功能盘点

## ✅ 已有能力（12 项）
1. 多格式文档接入（PDF 保留页码 / Word / Excel / PPT / MD / TXT / HTML）
2. 智能切分（Markdown 标题 + 段落感知 + 定长重叠，知识库级参数）
3. 混合检索（Chroma 向量 + jieba/FTS5 BM25 + RRF 融合）
4. LLM 重排（相关性精排，可开关）
5. SSE 流式问答 + 引用溯源（文档/页码/片段/相关度）
6. 多租户隔离 + RBAC 三级角色 + 用户注册 + 权限管理
7. 全操作审计（登录/注册/上传/删除/问答）
8. 异步索引（进度/失败重试/重启恢复/并发控制/重复文件检测）
9. 模型降级链（chat + embedding 双链路）
10. 安全（PBKDF2/JWT/限流/上传校验）
11. Docker 部署 + 架构/API/部署文档 + 27 项测试
12. 时区正确展示（UTC 存储，本地显示）
