## 三、项目经历

### 项目：KnowHub（知枢）— 企业级 RAG 知识库问答平台

**项目简介**：基于大模型的检索增强生成（RAG）知识库系统。上传 PDF/Word/Excel/PPT 等文档自动建立知识库，通过「向量 + 关键词混合检索 + LLM 重排」精准召回，以**带引用溯源（文档/页码）的流式问答**回答员工问题，内置多租户、RBAC 权限、操作审计、异步索引、模型自动降级等企业级能力。

**技术栈**：Python 3.11 · FastAPI · SQLAlchemy · ChromaDB · SQLite FTS5 · jieba · OpenAI SDK · Vue 3 · TypeScript · Ant Design Vue · Docker

**我的职责与成果**（按贡献挑 3~6 条，每条结构：动词 + 做了什么 + 量化结果）：

1. **独立设计并实现 RAG 检索链路**：文档解析（PDF 逐页提取保留页码、Word/Excel/PPT 含表格）→ 标题感知切分 → 向量化 → **向量（Chroma）+ 关键词（jieba + FTS5 BM25）+ RRF 融合**的混合检索 → LLM 重排，回答准确率与召回率显著优于单一检索，检索各阶段耗时可观测（毫秒级上报）。

2. **实现带引用溯源的流式问答**：基于 SSE 协议逐字流式输出，系统提示词强制编号引用 `[n]`，并设计「生成后 LLM 引用审计 + 回答正文标注过滤」双重校验，剔除无关引用，确保每条回答可溯源到具体文档与页码，引用元数据全量落库可审计。

3. **构建异步索引流水线**：上传即返回、后台解析→切分→向量化（asyncio 任务管理器，per-知识库串行锁 + 全局并发上限，避免 SQLite 写锁竞争），前端实时进度轮询，**服务重启自动恢复**中断任务，支持 sha256 内容哈希查重与一键重建索引。

4. **设计模型高可用方案**：对话与向量双链路多模型自动降级（主模型失败自动切换备用），通过 OpenAI 兼容协议抽象网关，**仅改一个配置变量即可切换任意大模型供应商**（DashScope/vLLM/私有化网关）。

5. **实现企业级权限与安全体系**：多租户数据隔离 + admin/editor/viewer 三级 RBAC（接口级强制校验）、JWT 认证、PBKDF2-SHA256（60 万轮）密码哈希、登录/注册/问答限流、AI 回答敏感信息自动脱敏、全操作审计留痕。

6. **开发企业控制台前端**：Vue 3 + TypeScript + Ant Design Vue 实现智能问答、知识库/文档管理（回收站、批量操作、版本替换、ZIP 导入）、系统管理（数据仪表盘、检索调试台、用户/租户/审计管理）等 5 大页面。

7. **工程化与质量保障**：Docker Compose 一键部署（nginx 反代 + SSE 配置）；编写 **27 项离线测试**（密码/JWT、切分器、解析器、RRF 融合、RBAC 隔离、上传→索引→删除全流程），覆盖核心链路；编写架构/API/部署文档。

**项目亮点**（面试口头可讲 1~2 个）：
- 检索的「三保险」：语义向量失效时关键词 BM25 兜底，RRF 融合兼顾二者；
- 重排的工程化约束：主体一致性检查（问题问谁答谁）+ 多文档覆盖保底，解决"问技术栈只答一篇文档"的真实缺陷；
- SQLite 生产级细节：WAL 模式、FTS 孤儿行清理、写事务提交后再建索引避免自锁死锁；
- 引用可信度闭环：生成 → 审计 → 标注过滤 → 落库，回答可验证、可追溯。
